# Interface asset provenance

- The Quarry launcher icon (`resources/icon.png`) is generated by `scripts/icon.go` from geometric shapes. It is covered by the root MIT license.
- The SVG files currently in this directory are Microsoft Fluent UI System Icons. Upstream revision: `a347af95478f989038cccbf085978865264c048a`. Source: https://github.com/microsoft/fluentui-system-icons/tree/a347af95478f989038cccbf085978865264c048a/assets . Their MIT license is distributed in `resources/licenses/fluent-icons-LICENSE.txt`.
- Windows Shell icons are obtained at runtime through Windows APIs; they are not extracted and redistributed as image files. Fluent SVGs provide fallbacks.
- Native Windows caption controls are provided by the platform.
- Treemap geometry is generated from scan data at runtime.
- README screenshots are generated by `internal/desktop/showcase_test.go` from fictional scan data.

## Historical assets
